Use Case #008

Find Recently Modified Files

Category: File Management

Find files modified within a configurable time window.

Shell Script

File: 008_kill_process.sh 

#!/bin/bash

set -euo pipefail

PID="${1:-}"

if [ -z "$PID" ]; then
    echo "Usage: $0 <PID>"
    exit 1
fi

if ! kill -0 "$PID" 2>/dev/null; then
    echo "Process $PID does not exist."
    exit 1
fi

kill "$PID"

echo "Termination signal sent to process $PID."
